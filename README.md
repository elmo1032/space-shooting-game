# Space Shooting Game

## Project Overview
The Space Shooting Game is a simple browser-based game where players control a spaceship to shoot down enemies and avoid getting hit. The game is designed using vanilla JavaScript and HTML5 canvas, creating an engaging experience with a retro sci-fi aesthetic.

## Installation
To run the game locally, you can simply clone the repository or download the project's files. Here are the steps:

1. Clone the repository or download the files:
   ```bash
   git clone <repository-url>
   ```
   
2. Navigate into the project directory:
   ```bash
   cd space-shooting-game
   ```

3. Open the `index.html` file in your web browser.

## Usage
- Use the **Left Arrow** key to move the spaceship left.
- Use the **Right Arrow** key to move the spaceship right.
- Press the **Space** bar to shoot bullets at incoming enemies.

Your score will be displayed at the top of the game window, and you have to prevent the enemies from reaching the bottom of the canvas to win.

## Features
- Control a spaceship using keyboard inputs.
- Shoot bullets to destroy enemies.
- Dynamic enemy spawning.
- Scorekeeping that updates as enemies are destroyed.
- Game Over screen displayed when an enemy reaches the bottom.

## Dependencies
This project uses the following libraries:
- [Tailwind CSS](https://tailwindcss.com) for styling.
- Font Awesome for icons (specifically a fallback in case custom images are not provided).

Since there is no `package.json` in the provided content, there are no additional dependencies specified.
