# Space Shooting Game

## Project Overview
The Space Shooting Game is a simple 2D game built using HTML, CSS, and JavaScript. Players control a spaceship and shoot at falling enemies, scoring points for each enemy destroyed. The game is designed for casual play and provides an engaging experience with a retro feel.

## Installation
To get started with the Space Shooting Game, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/space-shooting-game.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd space-shooting-game
   ```

3. **Open `index.html` in your web browser:**
   Simply double-click `index.html` or right-click and choose "Open with" followed by your preferred web browser.

## Usage
- **Controls:**
  - Use the **Arrow Right** key to move the spaceship right.
  - Use the **Arrow Left** key to move the spaceship left.
  - Press the **Space** key to shoot bullets at incoming enemies.

- **Objective:**
  - Destroy as many enemies as possible without letting them touch the bottom of the canvas. Your score increases with each enemy you hit.

## Features
- Smooth and simple controls for the spaceship.
- Intuitive shooting mechanics with falling enemies.
- Game over screen displaying the final score.
- A visually appealing interface using a radial gradient background and stylish fonts.

## Dependencies
The project utilizes the following external libraries:
- **Tailwind CSS** for styling and layout.
- **Font Awesome** for icons.
- **Google Fonts** for the Orbitron font.

These libraries are included in the `index.html` file via CDN links.

## Project Structure
The project consists of the following main files:

```
/space-shooting-game
│
├── index.html             # The main HTML file containing game logic and layout
```

The entire game logic is contained within the `<script>` tags in the `index.html` file, making it a single-file project that is easy to manage and deploy.
